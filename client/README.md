# Elite Paint

A responsive React and Vite website for Elite Paint, a Pune painting studio.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Quality checks

```bash
npm run lint
npm run build
```

## Deployment

The app uses hash-based routes, so it can be deployed as static files without server rewrite rules. All website photos are stored locally in `public/images`.
